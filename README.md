# ✳ NEUROFORM — Beyond Human

**Humanity, Reimagined.**

NEUROFORM is a futuristic, cyborg-inspired landing page that explores the intersection of human potential and machine intelligence. Built around a bold visual identity, modern UI/UX elements, and a responsive layout, the website imagines a world where biology and technology come together.

## 🚀 Project Overview

Designed as a futuristic digital experience, NEUROFORM presents the concept of human enhancement through technology.

The landing page combines immersive visuals, bold typography, interactive elements, and a dark aesthetic with vibrant lime-green accents to create a distinctive cyber-futuristic experience.

## ✨ Features

- **Futuristic Hero Section:** Bold typography, cyborg-inspired imagery, and engaging call-to-action buttons.
- **Modern UI/UX:** Minimal layouts, clean visual hierarchy, and consistent design language.
- **Animated Ticker:** A continuously moving banner highlighting the project's philosophy.
- **Interactive Navigation:** Smooth scrolling and responsive mobile navigation.
- **Feature Cards:** Three themed sections exploring intelligence, movement, and connection.
- **Responsive Design:** Layout adaptations for desktop, tablet, and mobile screens.
- **Micro-interactions:** Hover transitions and subtle visual effects.

## 🛠️ Technologies Used

- **HTML5** – Website structure and semantic content.
- **CSS3** – Styling, animations, responsive layouts, and visual effects.
- **JavaScript** – Interactive navigation and menu functionality.
- **Google Fonts** – Space Grotesk and DM Sans typography.

## 💻 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/ShubhiySharma/neuroform-site.git
```

**2. Navigate to the project directory**

```bash
cd neuroform-site
```

**3. Open the project**

Open `index.html` directly in your browser, or use the Live Server extension in Visual Studio Code for a better development experience.

## 🎨 Design Direction

The visual identity of NEUROFORM is built around:

- **Color Palette:** Deep black, charcoal, and electric lime.
- **Typography:** Space Grotesk for bold headings and DM Sans for readable body text.
- **Visual Style:** Cyber-futurism, minimalism, and immersive imagery.
- **Experience:** A balance between futuristic aesthetics, clarity, and usability.
